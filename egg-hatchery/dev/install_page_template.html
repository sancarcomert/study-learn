Yumurta Standı Kurulum

Her dosya için: Kopyala'ya bas, Studio'da belirtilen yerde o isimde yeni script aç, içindekini sil (Ctrl+A, Delete), yapıştır (Ctrl+V). Sıra önemli değil, hepsi bitince F5. Toplam __TOTAL__ dosya.

  1. ServerScriptService içinde Modules adında bir Folder olmalı. Üstteki __MODULE_COUNT__ ModuleScript onun içine gider.
  2. Script türünü doğru seç: ModuleScript, Script (sunucu) ya da LocalScript.
  3. Adı tam yaz, uzantı (.lua) yazma. Eski aynı adlı scriptin içeriği yeni halle değişir.
  4. Haritada "propy's booth" modelleri hazır olmalı (BoothAdapter bunları kullanır).
